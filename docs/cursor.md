# AI-EDT в Cursor: подключение и работа

Плагин AI-EDT запускает внутри 1C:EDT MCP-сервер. Cursor подключается к нему как MCP-клиент, и агент
Cursor получает инструменты EDT: чтение и запись модулей BSL, метаданные, формы, проверку запросов,
ошибки проекта, отладку, обновление информационной базы. Сервер отвечает, пока запущена EDT с
открытым проектом.

> **Установка и настройка агентом Cursor - одним промптом.** Откройте в Cursor папку проекта EDT,
> откройте чат (`Ctrl+L`), выберите режим Agent и вставьте:
>
> ```text
> Установи и настрой мне AI-EDT для Cursor полностью сам.
> Рецепт для агента: https://github.com/Desko77/ai-edt/blob/main/docs/cursor-agent-setup.md
> Прочитай его целиком и выполняй по шагам. Ничего не завершай принудительно.
> Если нужно мое действие - остановись и скажи, что именно сделать.
> ```
>
> Агент ставит плагин, включает нужные настройки, подключает сервер к Cursor, ставит скил и
> правило и проверяет результат. От вас понадобится два действия, агент попросит о них сам: закрыть
> EDT при первой установке и включить сервер `ai-edt` в настройках Cursor. Рецепт для агента -
> [cursor-agent-setup.md](cursor-agent-setup.md).
>
> Ниже - те же шаги вручную.

## 1. Сервер в EDT

Откройте **Window → Preferences → AI-EDT**:

1. Включите **Plain-text responses (for Cursor)**. Cursor не читает MCP-resources, в этом режиме
   результаты приходят обычным текстом.
2. Нажмите **Start** или включите **Start the server when EDT opens** - тогда сервер запускается
   вместе с EDT. По умолчанию автозапуск выключен.
3. Порт указан в поле **MCP port**, по умолчанию `12250`, и в строке состояния EDT. Вторая EDT на
   той же машине занимает следующий свободный порт: `12251` и далее.

Проверка:

```powershell
curl.exe http://localhost:12250/health
```

Ответ `status: ok` и `phase: ready` - сервер готов. `phase: indexing` - EDT еще загружает проект.

## 2. Подключение в Cursor

Создайте файл `.cursor/mcp.json` в корне папки, которую открываете в Cursor (обычно каталог проекта
EDT). Файл `%USERPROFILE%\.cursor\mcp.json` подключает сервер во всех проектах сразу.

```json
{
  "mcpServers": {
    "ai-edt": {
      "url": "http://localhost:12250/mcp"
    }
  }
}
```

- `"type": "sse"` не указывайте: сервер отвечает по Streamable HTTP, с `sse` Cursor не подключится.
- Другой порт - подставьте его в адрес.
- Включен флажок **Require bearer token** (по умолчанию выключен) - добавьте в запись
  `"headers": {"Authorization": "Bearer <токен>"}`. Токен - в поле **Bearer token** на той же
  странице настроек.

Затем разрешите сервер в Cursor - сам он новый сервер не включает:

1. Откройте настройки Cursor: `Ctrl+Shift+J` или значок шестеренки в правом верхнем углу окна.
2. Слева выберите раздел про MCP. В разных версиях Cursor он называется по-разному: **Tools & MCP**,
   **MCP** или **Tools & Integrations**.
3. В списке серверов найдите `ai-edt` и переведите переключатель справа от него во включенное
   положение.
4. Через несколько секунд рядом с именем загорается зеленая точка и появляется число инструментов -
   подключение готово. Красная точка или надпись об ошибке - смотрите раздел "Если не работает" ниже.

В Cursor CLI то же самое делают команды `cursor-agent mcp enable ai-edt` и
`cursor-agent mcp list-tools ai-edt`.

## 3. Скил и правило

Плагин дает агенту инструменты, скил объясняет, как ими пользоваться: какой инструмент брать под
задачу, какие проверки выполнять после правки, как забирать результат долгой операции. Без скила
агент тоже работает, но чаще читает модули целиком и правит файлы EDT в обход плагина.

Скил и правило для Cursor лежат в репозитории
[cursor-1c-skills](https://github.com/Desko77/cursor-1c-skills):

- `skills/ai-edt-tools` - каталог инструментов и типовые сценарии;
- `rules/mcp-tool-priority.mdc` - какой сервер брать под задачу и обязательные проверки.

Установка в текущий проект (из корня папки, открытой в Cursor):

```powershell
git clone --depth 1 https://github.com/Desko77/cursor-1c-skills.git "$env:TEMP\cursor-1c-skills"
New-Item -ItemType Directory -Force .cursor\skills, .cursor\rules | Out-Null
Copy-Item -Recurse "$env:TEMP\cursor-1c-skills\skills\ai-edt-tools" .cursor\skills\
Copy-Item "$env:TEMP\cursor-1c-skills\rules\mcp-tool-priority.mdc" .cursor\rules\
Remove-Item -Recurse -Force "$env:TEMP\cursor-1c-skills"
```

Скил и правило обращаются к серверу по имени `ai-edt` - это же имя стоит в `mcp.json` выше. Полный
набор скилов для 1С и его установщик описаны в README того репозитория.

## 4. Работа

Задачу пишете в чате Cursor в режиме Agent обычными словами. Агент сам выбирает и вызывает
инструменты плагина. Перед вызовом инструмента Cursor может запросить подтверждение - это
настраивается в Cursor.

Примеры:

```text
Покажи проекты EDT в рабочем пространстве и состояние их проверки.
```

```text
Найди все ссылки на Справочник.Номенклатура и сгруппируй их по модулям, формам и метаданным.
```

```text
Покажи структуру модуля объекта документа ЗаказКлиента и прочитай процедуру ОбработкаПроведения.
```

```text
Добавь в справочник Контрагенты реквизит КодПоставщика, Строка(20), выведи его на форму элемента
и проверь ошибки проекта по справочнику.
```

```text
Проверь запрос в процедуре ПолучитьДанные модуля менеджера отчета ОстаткиТоваров и исправь ошибки.
```

```text
Обнови конфигурацию базы данных.
```

Что учитывать:

- EDT с открытым проектом должна работать все время, пока агент работает: без нее инструменты не
  отвечают.
- Код BSL агент записывает инструментом записи модуля, а не правкой файла: так EDT сразу видит
  изменение и проверяет синтаксис. Если агент начал править `.bsl` напрямую, попросите делать это
  через AI-EDT - правило из шага 3 это и задает.
- Долгая операция (обновление базы, поиск по большой конфигурации) отвечает `status=Pending` с
  ключом `runKey`. Агент повторяет вызов с этим ключом и получает результат.
- Если EDT показала модальное окно, вызов отвечает `blockedByDialog` с текстом окна и его кнопками.
  Ответьте в окне сами или попросите агента нажать кнопку: `project_admin operation=answer_dialog`.
- Какие инструменты доступны агенту, задает пресет на странице **Window → Preferences → AI-EDT**,
  например только чтение.
- Плагин работает с конфигурацией и проектом, данных информационной базы он не читает.

## Если не работает

| Симптом | Что проверить |
|---|---|
| Cursor не подключается, `Connection failed` | EDT запущена, `/health` отвечает, порт в `mcp.json` совпадает, `"type": "sse"` нет |
| Сервер в списке, инструментов нет | переключатель у `ai-edt` в разделе MCP настроек Cursor выключен |
| Ответ `401` | включен **Require bearer token**, нужен заголовок с токеном |
| Результаты приходят пустыми или ссылками на ресурсы | не включен **Plain-text responses (for Cursor)** |
| `phase: indexing` | EDT еще загружает проект, дождитесь `ready` |
