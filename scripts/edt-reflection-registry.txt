# Reflective targets: what this plugin reaches by NAME at run time, where neither the compiler nor
# the bytecode pass can see it. Verified by scripts/check-edt-api.py against every release we claim
# to support.
#
# Mostly generated from the sources - the class a lookup is made on is followed through the variable
# it was put into, the same way the audit of 2026-08-06 did it by hand - and then kept here so the
# pairing survives and can be checked. The script fails when the sources reach an EDT class or
# member this file does not list, so the list cannot quietly fall behind the code.
#
# Three kinds of line:
#
#   <class> [member,member]   a type we depend on. Absence is a finding and fails the check.
#   probe <class>             one spelling among several tried in turn at run time, beside a path
#                             that is compiled and works. Absence is ordinary - that is what probing
#                             is for - so it is counted and shown, never failed.
#   id <string>               not a class at all: a project nature, a launch-configuration attribute
#                             key or value, a component or runtime type, a language id. Written like
#                             a class name by convention. It cannot be looked for in a jar, so it is
#                             recorded and NOT checked - a gap this census states rather than hides.
#                             Answering it needs the extension registry inside the bundles, which is
#                             a different tool.
#
# Known dead branch, kept visible on purpose:
#   com._1c.g5.v8.dt.mcore.LocalString resolves in NO supported release, and McoreFactory has no
#   createLocalString either, so the LocalString wrapping in BmObjectHelper never fires. It is
#   guarded and harmless, but the protection it looks like it gives is not there. Measured
#   2026-08-16 by this census - which is the sort of thing it exists to find.
